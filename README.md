# AG landing

A single preview page: a looping black-hole clip, "Into The Unknown", and contact and copyright lines.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # static output in dist/
```

The clip `public/media/unknown.{webm,mp4}` and `poster.jpg` come from `ag-suite/sim-intro-video/out/film_full_clean.mp4` (104.5–114 s, 1 s fade in and out, no audio).
